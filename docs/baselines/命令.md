# 命令（令）格式 Baseline

> 状态：命令定稿口径（代码修改前）  
> 依据：GB/T 9704-2012 §10.2；落款见 §7.3.5.3；未单列处援引第 5、7 章通用规则  
> 参考样例：`E:\red head\Red Head Helper\examples\特定-命令令-政府令.docx`（有瑕疵处以本基线为准）  
> 范围：以**公布令**为主（适用大多数命令场景）；原则：国标明文与产品收敛分档，减少返工

---

## 1. 范围与不做项

**本基线覆盖**

- 党政机关命令（令）首页/末页排版
- 发文机关标志、令号、正文、附件说明、签发人职务、签名章占位、成文日期、附注、附件另面、版记、页码

**本基线不做**

- 签名章图形/图片接入（只留占位，不生成印章）
- 机关印章、发文机关署名
- 标题、主送机关（公布令面向社会；本基线主体不排主送）
- 发文字号、红色分隔线
- 份号 / 密级和保密期限 / 紧急程度（见 §13：产品不提供，非国标禁令）
- 「签发人：×××」上行文版头标识（§7.2.6）
- `seal_mode`（有章/无章）选填与校验
- 本基线不重开「28 字/行字距」口径（沿用现有通用排版）

【产品】识别为命令时，**自动**将 `doc_kind` 切到命令并走本基线；确认页仍可手动改回。

自动判定（唯一规则）：

1. 发文机关标志槽位以「命令」或「令」结尾（如「××市人民政府令」）

未命中则保持通用（或其它已选文种）。不因正文偶尔出现「命令」二字、亦不因单独出现「第 N 号」误切。

## 2. 口径分档说明

只保留三档：

| 标记 | 含义 | 校验强度 |
|---|---|---|
| 【国标】 | GB/T 9704-2012 原文或可直接援引的通用条款 | 见下：强制 / 推荐 |
| 【收敛】 | 标准未写死时，本产品的唯一做法 | 硬校验 / 验收必过 |
| 【产品】 | 导出校验、字段、交互、占位尺寸等 | 产品行为校验 |

【国标】内再分：

| 子档 | 判定 | 示例 |
|---|---|---|
| **强制** | 验收必过 | 标志上边缘至版心上边缘 20 mm；令号/正文空行；§7.3.5.3 落款位置 |
| **推荐** | 按推荐实现，不以零容差硬杀 | 红色小标宋；版记线宽 0.35/0.25 mm |

## 3. 版面基准【国标】

与通用公文同一套（字距沿用现有引擎）：

| 项 | 值 |
|---|---|
| 纸型 | A4（210×297 mm） |
| 天头 / 订口 | 上 37 mm / 左 28 mm |
| 版心 | 156×225 mm（右 26 mm / 下 35 mm） |
| 网格 | 22 行 × 28 字 |
| 正文 | 3 号仿宋_GB2312，固定行距 = 版心高/22（约 29 pt） |
| 结构层次 | 一、黑体 / （一）楷体 / 1. 仿宋 / （1）仿宋；段首左空二字，回行顶格 |

页码【国标 §7.5】：4 号半角宋体阿拉伯数字，左右各一条一字线；一字线上距版心下边缘 7 mm；单页右空一字、双页左空一字。**命令首页显示页码**（信函首页不显示页码的规则不适用于命令）。

### 3.1 版心几何测点【产品】

以 mm 为准；pt ≈ mm × 72 / 25.4。

| 测点 | mm | pt（约） |
|---|---|---|
| 版心左缘 / 上缘 | 28 / 37 | 79.37 / 104.88 |
| 版心右缘 / 下缘 | 184 / 262 | 521.57 / 742.68 |
| 命令标志墨迹顶（相对纸顶） | 37+20=**57** | **161.57** |
| 页码一字线上沿距版心底 | 7 | 19.84 |

## 4. 整页要素顺序【收敛】

自上而下：

1. **发文机关标志**（命令/令）
2. **令号**
3. **正文**（无标题、无主送）
4. **附件说明**（选填）
5. **签发人职务 + 签名章占位**（可多组，主办在上）
6. **成文日期**
7. **附注**（选填）
8. **附件另面**（若有上传附件）
9. **版记**（仅当有抄送 / 印发机关 / 印发日期时）
10. **页码**

本基线**不**在标志上方排份号、密级、紧急程度。

---

## 5. 发文机关标志【国标 + 收敛】

【国标 §10.2】

- 由发文机关全称加「命令」或「令」字组成
- 居中排布
- 上边缘至版心上边缘为 **20 mm**
- 推荐红色小标宋体字

【收敛 / 产品】

- 机关名与「命令/令」之间**不空格**；不加「文件」
- 优先**单行**；字号按字体实测收缩，宽 ≤ 版心可用宽
- 字号 0.5 pt 量化；**下限 26 pt**；不低于下限时保持单行；仅低于下限仍超宽才允许回行（各行居中）
- 有输入已以「命令」或「令」结尾则不再重复拼接
- **联合发文机关**：同通用联合红头（机关名成块分行 + 右侧后缀上下居中）；右侧为「令」或「命令」（由标志文本尾缀决定；抽不到时默认「令」）；确认页改标志即可改尾缀，不另做单选

---

## 6. 空行规则【国标 + 收敛】

| 关系 | 空行 |
|---|---|
| 标志 → 令号 | 空 **2** 行【国标 §10.2】 |
| 令号 → 正文 | 空 **2** 行【国标 §10.2】 |
| 正文 → 附件说明（有） | 空 **1** 行【国标 §7.3.4】 |
| 正文或附件说明 → 首组签发人职务/章 | 空 **2** 行【国标 §7.3.5.3】 |
| 联合：组与组之间 | 空 **1** 行【收敛】 |
| 签名章 → 成文日期 | 空 **1** 行【国标 §7.3.5.3】 |
| 成文日期 → 附注（有） | **不空行**（附注在成文日期下一行）【国标 §7.3.6】 |

---

## 7. 令号【收敛】

- **必填**
- 国标只要求令号居中，**未规定**字距或是否空格；本产品收敛为无空格（非「国标要求无空格」）
- 形态**唯一**：`第{N}号`（N 为正整数，不编虚位：1 不编为 01）
- **展示时无空格**：输出「第1号」，不得输出「第 1 号」；本版不做「字间分散撑满」
- 不带年份、不带机关代字、不得含「〔〕」或发文字号结构
- 标志下居中；3 号仿宋_GB2312
- 参考样例「第 1 号」带空格 → **不以样例为准**（样例更近部分公报观感，但与本产品收敛不一致）

---

## 8. 正文【国标】

- 令号下空二行起排
- 3 号仿宋；段首左空二字，回行顶格
- 公布令通常一段到底；确需分层时层次字体同通用 §7.3.3
- 结构标题（h1–h4）导出设 `keep_with_next`【产品】

---

## 9. 附件说明【国标 §7.3.4】

- 选填；有则正文下空一行、左空二字
- 「附件」后全角冒号；一件不编序号；多件「附件：1.×××」；名称后不加标点；回行与附件名称首字对齐
- 附件另面：页码连续；版记在最后一面

---

## 10. 署名区（签名章版式）【国标 §7.3.5.3 + 产品】

### 10.1 国标位置

- 正文（或附件说明）下空二行起排
- 签名章：**右空四字**
- 签发人职务：在签名章左侧，与章之间**左空二字**（即职务右端到章左缘为空二字）；职务须**全称**
- 职务与章**以签名章为准上下居中**（对齐章的垂直中线，不是章的上沿/下沿）
- 成文日期：签名章下空一行，**右空四字**；数字写法同 §7.3.5.4
- 联合：主办在上，其余依次向下；与主办上下对齐；每行只排一个机关的职务+章；各行章左右对齐
- **不**编排发文机关署名；**不**盖机关印章
- 签名章一般用红色【国标·推荐】——本产品不着色印文，仅占位

### 10.2 姓名不进文本【国标理解 + 收敛】

签发人**姓名由签名章印文体现**，不是键盘排进职务行的汉字。  
职务行只排职务（如「市长」），**不得**排成「市长　张明远」。  
参考样例落款「市长　张明远」为用字代替章的权宜写法 → **不以样例为准**。

### 10.3 签名章占位【产品】

- 本产品**不生成**签名章图片，只输出占位框，供事后盖章或人工贴图
- 真章多为**扁长方形人名章**（不是圆形机关印，也未必是大正方形）；国标未规定边长
- 本基线占位框取**扁长方形**【收敛】：

| 项 | 产品取值 | 说明 |
|---|---|---|
| 占位宽 × 高 | **45 mm × 20 mm** | 产品占位，非国标尺寸 |
| 线型 | 0.5 pt 实线框 | 印刷前可视情况隐藏/删除框线 |
| 框内文字 | 无（空白） | 不印「签名章」提示字，避免误作正文 |

**【产品】垂直防压（必写进实现）**

- 国标「正文/附件说明下空二行」后排职务+章：占位在 Word/WPS 中多为浮动图形，**不自动占文字流高度**
- 约定：章的垂直中线与职务行垂直中线对齐；**章顶不得侵入正文（或附件说明）末行墨迹**；章高不得超过「空二行」所对应的网格高度（2 × 行距 ≈ **58 pt** / 约 **20.5 mm**）
- 当前占位高 20 mm ≈ 56.7 pt ＜ 58 pt，余量约 1.3 pt，因而能被「空二行」兜住；这是尺寸可成立的**约束条件**，不是国标推导出的唯一解
- **若未来改章高，必须同步核算空行数或上移规则**，否则章会压正文
- 成文日期的「章下空一行」以**章的下缘**起算，不以职务文字基线起算

几何关系（3 号一字宽 = 16 pt；版心右缘 ≈ 521.57 pt）：

| 量 | 计算 | 约值 |
|---|---|---|
| 右空四字 | 4 × 16 pt | 64 pt |
| 章右边界 | 版心右缘 − 64 | ≈ 457.57 pt |
| 章左边界 | 章右 − 占位宽 | 由 45 mm 换算 |
| 职务与章间隙 | 左空二字 = 32 pt | 职务右端 = 章左 − 32 pt |
| 成文日期右端 | 与章右边界对齐（右空四字） | ≈ 457.57 pt |

验收对占位宽高给 **±1 mm** 容差；右空四字位置按一字宽口径 ±1 pt。

### 10.4 职务字体【收敛】

3 号仿宋_GB2312（与成文日期同）。

## 11. 附注【国标 §7.3.6】

- 选填；成文日期**下一行**；左空二字；加圆括号

---

## 12. 版记【国标 + 收敛 + 产品】

【收敛】仅当存在抄送、印发机关、印发日期至少一项时输出；三项全空则整块不渲染。

【国标 §7.4】分隔线、抄送、印发规则同通用/纪要；线宽为【国标·推荐】。  
印发：字段只存日期，引擎在日期后加「印发」。  
`print_org` 与 `print_date` **同进同退**。

【产品】与纪要对齐的两条硬约束：

1. **防压字**：末页版记之前最后一行内容的行框底 + **1 行** ≤ 版记首条分隔线顶；不满足则加空行或将版记推至下一页。  
2. **消空白页**：版记为文档末元素时，其后补 **1 pt** 空段。

说明：

- 「不为版记留位而提前分页」指：**不在正文中间硬插分页符专为版记腾位**；末页放不下时仍允许把版记推到下一页（与第 1 条一致）。
- 信函「版记不加印发与分隔线」**不**适用于命令。

| 主送机关（主体） | 不输出 | 【收敛】公布令 |

| 「签发人：」版头标签 | 不输出 | 【收敛】 |

## 14. 分页【产品】

- 附件另面、版记钉底沿用现有引擎；防压字与 1 pt 尾段见 §12
- h1–h4：`keep_with_next`
- 命令常单页；多页时版记仍在最后一面版心内最下方

## 15. 字段与导出校验【产品】

### 15.1 建议字段

| 字段 | 必填性 | 说明 |
|---|---|---|
| `doc_kind` | — | 枚举含 `order`（命令） |
| 发文机关标志 | 必填 | 全称 +「命令」或「令」 |
| `order_no` | 必填 | 存 N 或「第{N}号」；展示统一无空格「第1号」 |
| `body_tree` | 必填 | 实现用结构树；对外可称正文 |
| `signers` | 必填 | `[{ "title": "市长" }, …]`；至少 1 条；**不含姓名**；**数组第 0 条即主办机关，其后顺序即排版自上而下顺序**（实现不得自行重排）；无需 `seal_placeholder` 字段（占位由引擎必出） |
| `date` | 必填 | 成文日期 |
| 附件说明 / 附注 / 抄送 / 印发机关 / 印发日期 | 选填 | 印发二者同进同退 |
| `seal_mode` | — | 命令下不使用 |

### 15.2 导出门槛

1. 标志非空，且以「命令」或「令」结尾  
2. 令号可解析为 `第{N}号`，且不含「〔〕」  
3. 正文至少一段非空  
4. `signers` 至少一条，且每条 `title` 非空  
5. 成文日期非空  
6. 若填印发：机关与日期同在；否则同缺  

页码由引擎必出。抄送/附注/附件说明不挡导出。

### 15.3 契约示例

```json
{
  "doc_kind": "order",
  "header": {
    "issuing_org_header": "江州市人民政府令",
    "order_no": "第1号"
  },
  "main": {
    "body_tree": [
      {"level": "p", "text": "《……办法》已经……现予公布，自2027年1月1日起施行。"}
    ],
    "attachment_caption": null,
    "signers": [{"title": "市长"}],
    "date": "2026年10月25日",
    "note": null
  },
  "footer": {
    "cc_recipients": null,
    "print_org": null,
    "print_date": null
  }
}
```

## 16. 验收要点

1. 标志墨迹顶 ≈ 纸顶 57 mm；红色小标宋；单行优先  
2. 令号为无空格「第{N}号」，居中；标志→令号、令号→正文均为空 2 行  
3. 无标题、无红线、无发文字号、无机关署名、无 `seal_mode`  
4. 职务行无姓名；章位为扁长方空框；职务—章—日期位置符合 §10  
5. 联合多组：主办在上，组间空 1 行，章左右对齐  
6. 有版记时防压字成立，且末元素后有 1 pt 空段  
7. 首页有页码；一字线上沿目标距版心底 7 mm（见 §16.1）  
8. 章顶不压正文；章高 ≤ 2 网格行高；日期起算自章下缘  

### 16.1 几何测点容差

| 检查项 | 期望 | 容差 |
|---|---|---|
| 标志墨迹顶 | 纸顶 57 mm | ±1.0 mm |
| 版心四缘 | 同 §3.1 | ±0.5 mm |
| 页码一字线上沿距版心底 | **7 mm**【国标 §7.5】 | 见下「页码测法说明」 |
| 章右边界 / 日期右端 | 右空四字 | ±1 pt |
| 职务与章间隙 | 左空二字 | ±1 pt |
| 占位框 | 45×20 mm 扁长方；高 ≤ 约 20.5 mm（58 pt） | ±1 mm |
| 章顶 vs 正文末行 | 不侵入正文墨迹 | 不得重叠 |
| 版记末条 | 与版心下缘重合 | ±0.5 pt（线宽推荐项） |
| 版记防压字 | 上文末行底 + 1 行 ≤ 首线 | 不得重叠 |

**页码测法说明【产品】**：引擎实现为 `footer_distance = 下白边 35 mm − 7 mm = 28 mm`（与现有通用文一致）。Word/WPS 对「页脚距 ↔ 一字线上沿」的取点可能不一致，已知有样例量到约 9 mm 而非 7 mm。本基线：

- **目标值仍写 7 mm**（国标）
- 命令阶段**不单独改页脚公式**（避免与通用文分叉）
- 验收：优先查引擎参数是否为「下白边 − 7 mm」；屏幕/打印实测允许 **+3 mm** 内偏差，超出再单独立项修页脚（全产品统一修，不在命令文种内特判）

## 17. 已锁定的产品决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 令号形态 | 无空格 `第{N}号` |
| 2 | 版记 | 复用纪要：防压字 + 末尾 1 pt 空段；不在正文中硬插分页专为版记腾位 |
| 3 | 联合组距 | 组与组之间空 1 行 |
| 4 | 签名章占位 | 扁长方 45×20 mm 空框；高须 ≤ 空二行（≈58 pt）；不印提示字；不接图片 |
| 5 | 姓名 | 不进职务文本；由章印体现 |
| 6 | 份号/密级/紧急 | 本基线删除字段（产品范围），非国标禁止 |
| 7 | 文种切换 | 仅按标志以「命令/令」结尾自动切换；确认页可改回 |
| 8 | 40 mm 方章假设 | **废弃**；改为扁长方产品占位 |
