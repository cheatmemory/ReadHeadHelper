# 纪要格式 Baseline

> 状态：纪要定稿口径（代码修改前）  
> 依据：GB/T 9704-2012 §10.3；未单列处援引第 5、7 章通用规则  
> 参考样例：`E:\red head\Red Head Helper\examples\特定-纪要-常务会议.docx`  
> 原则：适用大多数纪要；国标明文与产品收敛分档书写，减少返工

---

## 1. 范围与不做项

**本基线覆盖**

- 党政机关会议纪要的首页/末页排版
- 纪要标志、期号、标题、正文、附件说明、出席/请假/列席、成文日期、附注、附件另面、版记、页码

**本基线不做**

- 联合纪要双标志 / 多标志
- 纪要盖章、发文机关署名、签发人、签名章
- 「××文件」式发文机关标志与纪要标志并存
- 发文字号（由期号惯例替代，且仅一种形态）
- 红色分隔线
- 机关自定义纪要模板、可变版式开关
- 本基线不重开「28 字/行字距」口径（沿用现有通用排版实现，含文档网格等）

【产品】识别为纪要时，**自动**将 `doc_kind` 切到纪要并走本基线排版；确认页仍可手动改回通用或其他文种。

自动判定（满足任一即视为纪要，按从上到下优先）：

1. 纪要标志或发文机关标志槽位文本以「纪要」结尾（如「×××××纪要」）
2. 标题以「纪要」结尾，或标题含「会议纪要」
3. 文末出现「出席：」名单行（名目二字 + 全角冒号）

未命中则保持通用（或其它已选文种），不因正文偶尔出现「纪要」二字误切。

## 2. 口径分档说明

只保留三档：

| 标记 | 含义 | 校验强度 |
|---|---|---|
| 【国标】 | GB/T 9704-2012 原文或可直接援引的通用条款 | 见下：强制 / 推荐 |
| 【收敛】 | 标准未写死或写「可根据实际制定」时，本产品的唯一做法 | 硬校验 / 验收必过 |
| 【产品】 | 导出校验、字段、交互、实现算法等 | 产品行为校验 |

【国标】内再分两档，避免把「推荐」写成硬失败：

| 子档 | 判定 | 示例 |
|---|---|---|
| **强制** | 验收必过；偏离即不合格 | 标志上边缘至版心上边缘 35 mm；出席名单排法；页码位置规则；附件说明下空一行 |
| **推荐** | 按推荐实现，但**不**因细微偏差判不合格 | 分隔线推荐高度 0.35/0.25 mm；标志「推荐」红色小标宋（本产品仍实现为红色小标宋，线宽亦按推荐值落地，惟验收对线宽给容差、不以推荐措辞作零容差硬杀） |

正文中凡写「推荐……」的国标句，默认归入【国标·推荐】；未写「推荐/一般」的编排位置与结构要求，默认归入【国标·强制】。

不再使用「国标精神」等第四档标签。

## 3. 版面基准【国标】

与通用公文同一套（实现沿用现有引擎，本基线不另定字距紧缩参数）：

| 项 | 值 |
|---|---|
| 纸型 | A4（210×297 mm） |
| 天头 / 订口 | 上 37 mm / 左 28 mm |
| 版心 | 156×225 mm（右 26 mm / 下 35 mm） |
| 网格 | 22 行 × 28 字 |
| 正文 | 3 号仿宋_GB2312，固定行距 = 版心高/22（约 29 pt） |
| 结构层次 | 一、黑体 / （一）楷体 / 1. 仿宋 / （1）仿宋；段首左空二字，回行顶格 |

页码【国标 §7.5】：4 号半角宋体阿拉伯数字，左右各一条一字线；一字线上距版心下边缘 7 mm；单页右空一字、双页左空一字。纪要首页显示页码（信函首页不显示页码的规则不适用于纪要）。

### 3.1 版心几何测点【产品】

单位以 mm 为准；下列 pt 由 mm 换算（×72/25.4），供对照工具使用，容差见 §15。

| 测点 | mm | pt（约） |
|---|---|---|
| 版心左缘（相对纸左） | 28 | 79.37 |
| 版心上缘（相对纸顶） | 37 | 104.88 |
| 版心右缘 | 28+156=184 | 521.57 |
| 版心下缘 | 37+225=262 | 742.68 |
| 纪要标志墨迹顶（相对纸顶） | 37+35=72 | 204.09 |
| 页码一字线上沿距版心底 | 7 | 19.84 |

版记末条线与版心下缘重合（约 742.7 pt，容差 ±0.5 pt）。多页时页数应与 Word/WPS 打开结果一致（同现有预览验收口径）。

## 4. 整页要素顺序【收敛】

自上而下固定为：

1. 份号 / 密级和保密期限 / 紧急程度（有则见 §4.1）
2. **纪要标志**
3. **期号**（选填）
4. **标题**（选填）
5. **正文**
6. **附件说明**（选填）
7. **出席** → **请假** → **列席**
8. **成文日期**（选填）
9. **附注**（选填）
10. **附件另面**（若有上传附件；规则同现有通用附件页）
11. **版记**（仅当存在「主送移入 / 抄送 / 印发」任一要素时）
12. **页码**

### 4.1 份号 / 密级 / 紧急【国标 §7.2.1–7.2.3 + 收敛】

有则顶格居版心左边缘，按「份号 → 密级和保密期限 → 紧急程度」自上而下分行：

| 要素 | 字体字号 | 形态 |
|---|---|---|
| 份号 | 3 号仿宋；一般为 6 位阿拉伯数字 | 单行 |
| 密级和保密期限 | 3 号黑体；期限中数字用阿拉伯数字 | 单行 |
| 紧急程度 | 3 号黑体 | 单行 |

【收敛】上述三行均**不得回行**；回行会侵占标志上方垫高区，导致标志墨迹顶偏离 35 mm。

---

## 5. 纪要标志【国标 + 收敛】

【国标 §10.3】

- 由「×××××纪要」组成
- 居中排布
- 上边缘至版心上边缘为 **35 mm**
- 推荐红色小标宋体字

【收敛 / 产品】字号收缩算法（保证可复现）：

1. 优先目标：**单行**排下，宽 ≤ 版心可用宽（沿用现有可用宽比例与字体实测，不用「字数→字号」死表）
2. 字号搜索：在上限与下限之间按 **0.5 pt** 步进（或等价二分后再量化到 0.5 pt）
3. **下限 26 pt**：不低于此值时必须保持单行
4. 仅当 26 pt 仍超出可用宽时，才允许回行（回行后各行仍居中；词意完整）
5. 有份号/密级/紧急时，仍保证标志墨迹顶 = 版心顶 + 35 mm（沿用现有垫高：扣已占行与行内字身上方空白）
6. 不追加「文件」二字；输入已含「纪要」则不再重复拼接

---

## 6. 空行规则【收敛】

| 关系 | 空行 |
|---|---|
| 标志 → 期号（有期号） | 空 **1** 行 |
| 期号 → 标题（有标题） | 空 **2** 行 |
| 标志 → 标题（无期号、有标题） | 空 **2** 行 |
| 标志 → 正文（无期号、无标题） | 空 **2** 行 |
| 标题 → 正文 | 空 **1** 行 |
| 正文 → 附件说明（有附件说明） | 空 **1** 行【国标 §7.3.4】 |
| 正文或附件说明 → 出席（或请假/列席之首条有内容者） | 空 **1** 行【国标 §10.3】 |
| 名单各块之间（出席→请假→列席） | 各块「依次另起一行」，块间**不再**额外空行 |
| 名单 → 成文日期（有成文日期） | 空 **1** 行 |
| 成文日期 → 附注（两者皆有） | **不空行**（附注在成文日期下一行，同 §7.3.6） |
| 名单 → 附注（无成文日期、有附注） | 空 **1** 行 |

「正文或附件说明下空一行」：有附件说明时，从**附件说明末行**起算。【国标】

---

## 7. 期号【收敛】

- 选填
- 形态**唯一**：`第{N}期`（N 为正整数，不编虚位：1 不编为 01）
- **展示时无空格**：输出「第18期」，不得输出「第 18 期」
- 不支持 `〔YYYY〕第{N}期`、发文字号式等其它写法
- 标志下居中；3 号仿宋_GB2312
- 与标志、标题/正文的空行见 §6

---

## 8. 标题【收敛】

- 选填
- 有则：2 号小标宋，居中；回行时**不拆词**（不在词中切断）
- 不把「梯形 / 菱形」等形状要求作为排版合格条件，亦不作不合格判定依据
- 无标题时直接按 §6 接正文

---

## 9. 主送【收敛】

- 默认不在主体编排主送
- 若用户填写主送：移入版记，标签为「主送」，编排方法同抄送（§7.4.2）；与抄送同时存在时，主送在抄送上一行，两行之间不加分隔线

---

## 10. 出席 / 请假 / 列席

### 10.1 排法【国标 §10.3】

在正文或附件说明下空一行，左空二字编排名目二字，后标全角冒号；冒号后标注单位、姓名；回行时与冒号后的首字对齐。

| 名目 | 必填性 |
|---|---|
| 出席 | 见 §10.2【产品】 |
| 请假 | 选填 |
| 列席 | 选填 |

有内容的名目块按「出席 → 请假 → 列席」顺序出现；无内容的名目整块省略。

### 10.2 产品必填【产品】

- 导出默认要求「出席」有内容
- 允许用户在确认页勾选「本件无出席名单」后放行
- 请假、列席永不挡导出

### 10.3 字体【收敛】

| 片段 | 字体字号 |
|---|---|
| 名目二字（出席/请假/列席） | 3 号黑体 |
| 紧随的全角冒号 | 3 号黑体（与名目同字体） |
| 冒号后的单位、姓名等 | 3 号仿宋_GB2312 |

说明：国标未写明冒号字体；本基线收敛为与名目同为黑体。

### 10.4 缩进【收敛】

- 左空二字 = 2 × 3 号字宽（与现有落款「右空 N 字」同一一字宽口径）
- 回行与冒号后首字对齐 = 悬挂：左缩进 = 左空二字 +「名目二字+全角冒号」实测宽；悬挂量 =「名目二字+全角冒号」实测宽
- 禁止把样例里的 47.25 pt 等数写进实现常量；以实现时测量为准

### 10.5 名单书写【收敛】

- 多人之间**统一用顿号「、」**（不用逗号「，」）
- 末尾不加句号
- 默认识别/排版目标形态：`单位（或职务）+姓名`（如：`市发展改革委主任刘志强`）
- 兼容导入：`姓名（职务）`；以及误用逗号分隔的名单（写入确认态时归一为顿号）
- 参考样例「列席」块使用了逗号，视为样例瑕疵，**不以样例逗号为准**

---

## 11. 成文日期【收敛】

- **选填**（可出现，不挡导出）
- 有则：3 号仿宋_GB2312；右空四字编排（一字宽 = 3 号字宽；参考样例 right indent = 64 pt）
- **不**编排发文机关署名，**不**盖章，**不**出现 `seal_mode`
- 位置与空行见 §4、§6
- 数字写法同 §7.3.5.4：年月日标全，月日不编虚位

---

## 12. 附注【国标 §7.3.6 + 收敛】

- 选填
- 有则：左空二字、加圆括号
- 位置：
  - 有成文日期：成文日期**下一行**（不空行）【国标 §7.3.6】
  - 无成文日期：名单下空一行【收敛】

---

## 13. 版记【国标 + 收敛 + 产品】

【收敛】仅当存在以下至少一项时输出版记：主送（移入）、抄送、印发机关、印发日期。

【国标 §7.4】

- 分隔线与版心等宽；首末条粗线（推荐 0.35 mm），中间细线（推荐 0.25 mm）→ 线宽属【国标·推荐】，按推荐值实现并给验收容差
- 抄送：4 号仿宋，左右各空一字；「抄送」后全角冒号；回行与冒号后首字对齐；末机关后标句号
- 印发机关和印发日期：4 号仿宋；机关左空一字、日期右空一字；日期用阿拉伯数字标全，后加「印发」
- 末条分隔线与公文最后一面版心下边缘重合

【产品】版记与末页的两条硬约束：

1. **防压字（兼作下条余量检查）**：末页在版记之前的最后一行内容（正文/附件说明/名单/成文日期/附注等，以实际最后输出者为准）的行框底到版记首条分隔线顶，至少留 **1 行**行距。即：上文末行底 + 1 行 ≤ 版记首线顶。若不满足，引擎须先增加空行或将版记推至下一页，避免内容被版记压住。
2. **消空白页**：当版记为文档末元素时，在版记之后补一个 **1 pt** 高的空段（极矮段落，不占网格行语义）。用于消除部分 Word/WPS 在版记钉底后多出一页空白的问题。第 1 条留下的 1 行空距，同时作为本条补段后仍不致与上文重叠的余量检查。

说明：信函「版记不加印发与分隔线」的规则**不**适用于纪要。

## 15. 分页【产品】

- 附件另面、版记钉底等沿用现有通用引擎行为；版记防压字与版记后 1 pt 空段见 §13
- **段首结构标题**（`body_tree` 中 level 为 h1–h4 的段，如「三、关于冬季安全生产」）导出时设置 `keep_with_next`（与下一段同页），避免标题落在页末、其正文落到次页
- 除上条与 §13 外，本基线不另定更细的孤立行 / 段中分页规则
- 验收：同一 IR 导出的 docx，在 Word 与 WPS 中页数一致；版记在最后一面版心内最下方；结构标题不与其紧邻正文跨页分离；不因版记多出空白页

## 16. 字段与导出校验【产品】

### 16.1 建议字段

| 字段 | 说明 |
|---|---|

| 纪要标志 | 必填；可复用机关标志槽位，语义改为纪要标志 |
| `issue_no` | 期号，选填；仅存 N 或整串「第{N}期」；展示统一为无空格的「第18期」形态 |
| `title` | 选填 |
| `body_tree` | 必填 |
| `attendance` | 出席文本 |

| `liexi` | 列席文本 |

必须同时满足：

1. 纪要标志非空  
2. 正文至少一段非空

成文日期、期号、标题、印发等均不挡导出。页码由引擎必出，不进表单必填列表。

## 17. 验收要点

### 17.1 行为与版式

1. 标志墨迹顶 ≈ 纸顶 72 mm（版心顶 + 35 mm）；优先单行；字号量化到 0.5 pt；不低于 26 pt 时不回行  
2. 全程无红色分隔线、无机关署名、无印章、无 `seal_mode`  
3. 期号若出现，仅为无空格「第{N}期」（如「第18期」），居中  
4. 空行关系符合 §6；有附件说明时，名单空行从附件说明下起算  
5. 「出席：」名目与冒号为黑体，其后名单为仿宋；回行与冒号后首字齐平；多人顿号分隔  
6. 有成文日期：名单下空一行，右空四字；附注在其下一行、左空二字加括号  
7. 无出席且未确认「本件无」→ 拒绝导出；确认后→ 允许  
8. 份号/密级/紧急均为单行顶格，字体符合 §4.1  
9. 结构标题与下一段同页（`keep_with_next`）  
10. 版记首线之上至少留 1 行空距，不被正文/名单等压住  
11. 版记为末元素时，其后有 1 pt 空段；不因此多出空白页  

### 17.2 几何测点（相对 §3.1）

| 检查项 | 期望 | 容差 |
|---|---|---|
| 版心四缘 | 左 28 / 上 37 / 右缘 184 / 下缘 262 mm | ±0.5 mm |
| 标志墨迹顶 | 纸顶 72 mm | ±1.0 mm |
| 页码一字线上沿距版心底 | 7 mm | ±0.5 mm |
| 版记末条线 | 与版心下缘重合 | ±0.5 pt（约）；线宽属推荐项 |
| 成文日期右空 | 4 × 3 号字宽 | ±1 pt |
| 版记防压字 | 上文末行底 + 1 行 ≤ 版记首线 | 不得重叠 |
| 版记后 1 pt 空段 | 版记为末元素时存在 | 有/无 |
| 无多余空白页 | 不因版记钉底多出一页 | 页数合理 |
| 双引擎页数 | Word 与 WPS 一致 | 0 |

## 18. 已锁定的产品决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 出席 | 默认要有内容；允许「确认无」后放行 |
| 2 | 期号形态 | 只保留无空格 `第{N}期`（如「第18期」） |
